# AEA - Experimental Analysis of Algorithms

Faculty of Computer Science, Alexandru Ioan Cuza University of Iasi (FII UAIC)

# Overview

This repository contains laboratory work, assignments, implementations, experiments and statistical analysis developed for the Experimental Analysis of Algorithms (AEA) course at the Faculty of Computer Science, UAIC.

# The course focuses on:

empirical evaluation of algorithms
performance measurement
benchmarking methodologies
statistical analysis of experimental results
reproducibility of experiments
comparative analysis between algorithms

# The repository may include:

algorithm implementations
benchmarking scripts
statistical hypothesis testing
data visualization
experimental reports
datasets used during evaluation
